## 공격 규칙과 호환성

- 마스터가 종료 시각 **이전**에 수신하고 수락한 공격 확정만 수동 공격으로 인정한다. 클라이언트 입력 시각으로 판정을 소급하지 않는다.
- 확정 수락 후 타격 시점이 제한시간을 넘어도 저장한 피해를 한 번 적용한다. 해당 턴의 자동 공격은 생성하지 않는다.
- 시간 만료가 먼저 확정되면 기존 무작위 자동 공격 흐름을 사용하고 수동 공격은 거절한다.
- 확정 후 타격 요청이 3초 동안 없으면 마스터가 확정 피해를 적용한다. 이후 타격·결과·완료 알림은 중복 적용하지 않는다.
- 새 RPC 형식은 이전 형식과 호환되지 않으므로 Photon GameVersion을 `1`에서 `2`로 변경했다. 함께 플레이할 클라이언트는 모두 새 버전을 사용해야 한다.
- 저장 파일 형식·구매·정산 정책은 변경하지 않았다.

- Unity 실제 Input System 검증: **8개 통과**. ESC 입력 이벤트 취소, 활성 상태·오버라이드 보존, 20회 반복 취소, 비활성 액션, OnDisable/OnDestroy 중복 정리, G 재설정, 사용자 지정 키 취소, JSON 저장·복원을 확인했다. `QARegressionChecks.KeyBindings()`를 Editor에서 재실행할 수 있다.

## 검증 한계

순수 상태 테스트와 오프라인 AI 대전은 실제 Photon 두 클라이언트 통신을 대체하지 않는다. 실제 네트워크 지연·패킷 손실·호스트 이탈, 모든 외형의 타격 애니메이션, 자물쇠 미니게임 성공·실패 후 실제 청각 확인, 장시간 경기, 실제 구매·정산은 별도 환경에서 재검증해야 한다. 이번 런타임 재검증은 정상 F 처리 메서드 호출을 사용했으며 물리 키보드 입력 검증과 구분한다. 이 보고서는 전체 76개 항목의 출시 승인을 뜻하지 않는다.
