# AI 모드 아이템 QA 체크리스트

작성 기준: 2026-11-28 / 현재 프로젝트 소스·아이템 데이터·AI 프리팹

각 항목은 **준비 조건을 맞춘 뒤, 확인 사항이 기대대로 동작하는지 검사**한다. 모든 항목은 미실행이다. 기존 케이스 ID는 유지했다.

## 공통 준비

- 사람 1명 + AI 모드에서 진행한다. 비교 테스트는 회차마다 상태를 초기화하고 지정한 조건만 바꾼다.
- 별도 표기가 없으면 AI 현재/최대 기력 **8/8**, 인벤토리 **8칸**, 양측 마을 HP **5000**, 방어막·기본 방어력 **0**, 기존 효과·사용 이력·락픽 **없음**이다.
- 제안 선택 테스트는 나무 HP **30000**으로 준비한다. 사용·훔치기 테스트는 나무 HP **24000**, 마지막 웨이브(**CurrentWave=2**, 최대3)로 준비한다.
- AI 일반 사용 임계값은 **30점**, 훔치기 임계값은 **50점**이다. **효과 테스트**에서 AI가 아이템을 안 쓰면 임계값을 일시적으로 낮추고, 시험 뒤 원복한다. 사용 판단 테스트의 임계값은 바꾸지 않는다.
- 조건은 **선택 또는 사용 직전의 실제 값**이다. 제안으로 새로 받은 아이템이 준비한 인벤토리 구성을 바꾸지 않도록 확인한다.

**사용할 툴:** `ItemOffer 지정`으로 다음 선택지를 예약하고, `AI 판단 모니터`에서 제안 선택·사용·훔치기 점수와 제외 사유를 확인한다. 시작 아이템은 `PlayerManager > QA 시작 아이템`으로 지정할 수 있다. 현재 툴에 없는 HP·기력·상태·타이밍 편집이 필요하면 별도 준비 수단을 사용하고, 준비할 수 없으면 보류한다.
