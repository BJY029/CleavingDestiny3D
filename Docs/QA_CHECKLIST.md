# CleavingDestiny3D QA 체크리스트

로비 → PvP/AI 대전 → 턴 진행·마을 성장 → 결과·보상 → 로비 복귀 흐름과 관련 기능을 점검한다.
이 문서는 테스트 계획 및 기록 양식이다. 작성 시점에 실제 플레이 검증은 수행하지 않았으며 모든 항목은 **미실행** 상태다.

실행 기록: [2026-11-10 QA 보고서](QA_REPORT_2026-11-10.md). 아래 표는 재사용하는 원본 양식이며, 회차별 판정과 부분 확인·차단 사유는 실행 보고서에 기록한다.

## 실행 기준

| 우선순위 | 의미 | 처리 기준 |
|---|---|---|
| P0 | 실행 불가, 진행 중단, 결과 오류, 재화·저장 데이터 문제 | 최우선 확인, 전 항목 통과 필수 |
| P1 | 주요 기능 및 안정성 오류 | 전체 기능 QA에서 확인, 미해결 오류 기록 |
| P2 | 표시·연출·사용성 문제 | 마무리 점검, 발견 사항 기록 |

- Windows 실행 빌드를 기본으로 한다. Editor 결과는 보조 증거로 구분한다.
- 서로 다른 테스트 계정의 클라이언트 2개와 구매용 테스트 재화를 준비한다.
- 저장 손상·로컬 값 변경 테스트는 별도 테스트 계정과 복사한 저장 데이터로 진행한다. 원본은 백업한다.
- 가격·보상·아이템 수치는 해당 빌드의 설정 및 서버 정책을 기준으로 비교한다.
- 상태는 `미실행 / 통과 / 실패 / 차단 / 해당 없음` 중 하나로 기록한다. 차단·해당 없음에는 사유를 남긴다.
- 아래 체크박스는 실행 완료 여부다. 체크만으로 통과를 의미하지 않으며 결과 표에 실제 판정을 기록한다.
