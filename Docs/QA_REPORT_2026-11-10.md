# CleavingDestiny3D QA 실행 보고서 — 2026-11-10

## 판정과 범위

**출시 빌드 기준 불합격. Windows 빌드를 막는 P0 오류 2건을 확인했다.** Editor에서는 로비, 매칭 취소·재시작, AI 대전 일부, 아이템 선택, 공격, 마을 강화, 상점 조회·장착, 친구 방, 키 설정을 실행했다. 발견 오류는 수정하지 않았다.

체크리스트 76개 항목을 분류했다. **통과 5 / 실패 3 / 차단 26 / 미실행·부분 확인 42.** 통과 5개는 아래에 명시한 Editor 시나리오의 결과이며 실행 빌드의 통과를 뜻하지 않는다. 여러 조건을 가진 항목은 일부를 실행했더라도 전체를 확인하지 못하면 미실행으로 남겼다. 전체 QA 완료 또는 출시 승인 보고서가 아니다.

## 확인된 제품 오류

### B001 — P0 — Editor 전용 메서드 호출로 Windows 빌드 실패

- 관련: C01 및 실행 빌드가 필요한 항목.
- 재현: 현재 활성 Windows64 대상으로 로비·게임·마을 씬을 포함해 비개발 빌드 실행. 출력 경로 `Builds/QA/CleavingDestiny.exe`.
- 기대: 플레이어 스크립트 컴파일 및 실행 파일 생성.
- 실제: `ForTestBranchSystem.cs(19,21): CS0117: SaveManager does not contain a definition for ResetSaveForTest`.
- 근거: `Assets/0_Scripts/PlayerData/ForTestBranchSystem.cs:19`에서 무조건 호출하지만, `Assets/0_Scripts/Save/SaveManager.cs:194` 이후 메서드는 `#if UNITY_EDITOR` 안에 있다.
- 확인: 유효 출력 경로의 Windows 빌드 1회에서 재현. 수정 없음.

### B002 — P0 — WeatherMaker의 Editor 전용 필드를 플레이어 코드에서 참조

- 관련: C01 및 실행 빌드가 필요한 항목.
- 재현: B001과 동일한 Windows 빌드.
- 실제: `WeatherMakerCloudProbeScript.cs(48,17)`, `(50,34)`에서 `CS0103: blackTexture does not exist in the current context`.
- 근거: `Assets/99_ImportAssets/WeatherMaker/Prefab/Scripts/Clouds/WeatherMakerCloudProbeScript.cs:65`의 필드 선언은 `#if UNITY_EDITOR` 안에 있으나 `OnDestroy()`의 참조는 밖에 있다.
- 영향: 플레이어 스크립트 컴파일 실패 → Addressables 빌드 실패 → 실행 파일 생성 불가.
- 확인: B001과 같은 빌드 1회에서 두 오류를 함께 검출. 다른 플랫폼·개발 빌드는 미검증. 수정 없음.
- 증거: [Windows 빌드 오류](QA_EVIDENCE/windows-build-errors.json). 빌드 도구 요약의 errors=0은 선행 Addressables 컴파일 실패를 반영하지 못하므로 콘솔의 실제 오류를 판정 근거로 삼았다.

### B003 — P1 — 키 재설정 취소 시 무한 재귀와 StackOverflowException

- 관련: O03.
- 재현:
  1. 로비 → 옵션 → 키 설정.
  2. 상호작용(F)의 키 버튼 클릭.
  3. 키 입력 대기 중 ESC 입력.
- 기대: 재설정만 취소하고 F 표시와 기존 바인딩을 유지.
- 실제: `StackOverflowException` 및 `StackOverflowException while executing InputSystem.onEvent callbacks`. 정상 키 표시로 복구하지 못하고 이후 `Any Key` 표시와 `<Keyboard>/anyKey` 오버라이드가 관찰되었다.
- 근거: `Assets/0_Scripts/Option/KeyBindOption.cs:267`의 OnCancel이 `CancelRebinding()`을 호출하고, `:294`에서 같은 작업의 `Cancel()`을 다시 호출한다. 스택에서 이 경로가 반복된다.
- 확인: Editor 재설정 취소 1회에서 재현. 프로세스 종료는 관찰하지 않았으며 배포 빌드 재현은 빌드 실패로 미검증.
- 증거: [취소 오류 스택](QA_EVIDENCE/keybind-cancel-errors.json), [오류 후 화면](QA_EVIDENCE/keybind-cancel.jpg).
- 정리: 테스트 전 키 오버라이드 문자열로 사용자 설정 파일을 복원했다. 제품의 취소 구현은 수정하지 않았다.

### B004 — P2 — AI 대전 초기화 중 VillageVFXBase 조회 실패

- 관련: C05, P05.
- 재현: 로비 → AI 대전 → 순서 결정 제한시간 만료 → 플레이어 준비.
- 실제: `[PlayerStatus] There is no VillageVFXBase. ActorNumber=1` 오류.

- 영향: 해당 호출은 VFX 갱신 없이 반환한다. 이후 본 게임과 마을 진입은 계속됐다. 보호막 효과가 계속 누락되는지까지는 확인하지 않았으므로 지속적인 시각 오류로 단정하지 않는다.
- 확인: 첫 AI 대전 초기화 1회에서 관찰.
- 증거: [Editor 콘솔](QA_EVIDENCE/editor-console-initial.json).

- 재현: 한국어 로비에서 온라인 매칭, 친구 방, 상점 및 AI 대전 UI 열기.

- 확인: 여러 화면에서 직접 관찰. 다른 지원 언어는 미검증.

## QA 도구 오류와 추가 관찰

### T001 — QA 도구 — 기존 상점 모의 테스트 컴파일 실패

`dotnet run --project Tools/Tests/ShopFlow` 실행 결과 종료 코드 1. `AxeShopController.cs:240`이 사용하는 `LocalizationManager`, `CSV_Type`을 테스트 프로젝트가 제공하지 않아 CS0103 오류가 발생했다. 테스트 케이스는 실행되지 않았다. 과거 통과 기록을 이번 실행의 결과로 사용하지 않았다.

### O001 — 추가 재현 필요 — 턴 경계에서 지연된 공격 요청 거부

첫 AI 경기에서 F 공격 게이지를 열고 확정한 뒤 `[ERROR]It is not Requester Turn`이 발생했다. 스택은 `PlayerAnimationController.PlayPlayerImpactAsync → FirstPersonAxeHit → PlayerController.RequestAttackAtImpact → ItemHandlingSystem.RPC_RequestAttack():720`이다.

입력 시점이 턴 제한시간과 가까웠다. 턴 만료 처리와 0.35초 지연된 공격 콜백의 경쟁 가능성이 있으나, 입력·서버 시각을 함께 기록하지 못했으므로 원인이나 공격 중복을 확정하지 않는다. 경기 진행은 계속됐다. 제한시간 직전 공격을 반복하며 피해 적용 횟수와 턴 전환 횟수를 검증해야 한다. 증거는 [Editor 콘솔](QA_EVIDENCE/editor-console-initial.json)에 포함돼 있다.

## 종료 상태와 재개 조건

- 게임 코드·씬·프리팹의 오류 수정 없음. QA 보고서와 증거만 추가했다.
- 처음부터 수정돼 있던 `SceneLoader.cs`, `GameThemeCatalog.asset` 및 기존 미추적 파일은 보존했다.
- 빌드 중 자동 직렬화된 WeatherMaker URP 프로필과 BlueTent/RedTent 프리팹은 테스트 전 상태로 복원했다. 복원 전 diff는 [자동 변경 기록](QA_EVIDENCE/unity-build-generated.patch)에 보관했다.
- 시험 장착은 캐릭터 `character_basic`, 도끼 `axe_iron`으로 복원했다. 키 바인딩은 테스트 전의 Move/S 오버라이드만 있는 문자열로 복원했다.
- Editor는 플레이 모드를 종료하고 QA 시작 시 열려 있던 GameScene으로 돌아왔다.
- B001/B002가 해결된 Windows 빌드와 독립된 두 클라이언트가 있으면 C01~C12부터 재검증해야 한다. 서버 구매·보상·저장 손상 검증에는 격리된 테스트 계정 및 데이터가 필요하다.
- B003은 키 입력을 다시 시험하기 전에 수정·재검증이 필요한 항목이다. 이번 회차는 해당 예외와 빌드 차단을 확인한 뒤 종료했으며, 장시간·전체 아이템·모든 외형 QA는 수행하지 않았다.
